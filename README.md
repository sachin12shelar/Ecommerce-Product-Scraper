# Ecommerce Product Scraper

A Python web scraping project that collects ecommerce product information
from Books to Scrape, a website designed for scraping practice.

## Project Overview

This scraper automatically extracts product information from multiple
pages and exports the collected data into an Excel file.

## Features

- Scrapes products across multiple pages
- Extracts product names
- Extracts product prices
- Captures product availability
- Collects product URLs
- Removes duplicate products
- Logs scraping errors
- Generates a scraping summary
- Exports results to Excel
